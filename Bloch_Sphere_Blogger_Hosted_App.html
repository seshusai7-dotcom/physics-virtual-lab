Bloch’s Sphere — Geometrical Representation of a Single Qubit

The Bloch sphere is a geometrical representation of the state of a single qubit. It is an imaginary unit sphere (r = 1) used to represent pure single-qubit states as points on its surface, while mixed states occupy the interior ball (r < 1):

  • North Pole (θ = 0): Selected to represent the computational basis state |0⟩ (e.g., spin-up ↑).
  • South Pole (θ = π): Selected to represent the computational basis state |1⟩ (e.g., spin-down ↓).
  • Surface Points (0 < θ < π, 0 ≤ φ < 2π): All other points on the unit surface represent pure coherent superposed states in the single-qubit state space.
  • Spherical Coordinates (r, θ, φ): The state vector |ψ⟩ makes polar angle θ with the positive z-axis, and its equatorial projection (azimuth) makes angle φ with the positive x-axis.

Qubit State on the Bloch Sphere

A general normalized pure qubit state is written as |ψ⟩ = α|0⟩ + β|1⟩ with |α|2 + |β|2 = 1. Eliminating unobservable global phase, we parameterize it in spherical angles as:

|ψ⟩ = cos(θ2)|0⟩ + eiφsin(θ2)|1⟩    — Eq. (1)
  • θ (theta) → Polar angle (0 ≤ θ ≤ π)
  • φ (phi) → Azimuthal angle (0 ≤ φ < 2π)
Case (1): Let θ = 0 and φ = 0, then Eq. (1) becomes:
|Ψ⟩ = cos(0)|0⟩ + e0sin(0)|1⟩ = 1·|0⟩ + 0·|1⟩  ⇒  |Ψ⟩ = |0⟩
Case (2): Let θ = π and φ = 0, then Eq. (1) becomes:
|Ψ⟩ = cos(π2)|0⟩ + e0sin(π2)|1⟩ = 0·|0⟩ + 1·|1⟩  ⇒  |Ψ⟩ = |1⟩
Case (3): Let θ = π/2 and φ = 0, then Eq. (1) becomes the equal superposition (Hadamard |+⟩) state:
|Ψ⟩ = cos(π4)|0⟩ + e0sin(π4)|1⟩ = 1√2(|0⟩ + |1⟩) = |+⟩

Coordinates on the Sphere

Each pure qubit state corresponds to a Cartesian point (x, y, z) = (sin θ cos φ, sin θ sin φ, cos θ) on the unit sphere:

  • Case (1): Along the North Pole (θ = 0): |ψ⟩ = |0⟩ (Pure basis state |0⟩) → Bloch vector: (0, 0, 1).
  • Case (2): Along the South Pole (θ = π): |ψ⟩ = |1⟩ (Pure basis state |1⟩) → Bloch vector: (0, 0, −1).
  • Case (3): Along the Equator (θ = π/2): Global phase does not affect physical observables, so all points around the equator represent equal 50/50 superpositions with different relative phases φ:
    • If φ = 0 (Hadamard state |+⟩ = (|0⟩+|1⟩)/√2) → Bloch vector: (1, 0, 0) → Along +x-axis.
    • If φ = π (State |−⟩ = (|0⟩−|1⟩)/√2) → Bloch vector: (−1, 0, 0) → Along −x-axis.
    • If φ = π/2 (State |+i⟩ = (|0⟩+i|1⟩)/√2) → Bloch vector: (0, 1, 0) → Along +y-axis.
    • If φ = 3π/2 (State |−i⟩ = (|0⟩−i|1⟩)/√2) → Bloch vector: (0, −1, 0) → Along −y-axis.

Mixed States & Interior of the Bloch Ball (r < 1)

While pure states lie strictly on the outer surface (r = |r⃗| = 1), mixed states represent classical statistical ensembles ρ = p|ψ⟩⟨ψ| + (1 − p)|ψ⊥⟩⟨ψ⊥| caused by environmental decoherence or entanglement with another qubit:

ρ = 12(I + rxX + ryY + rzZ) |r⃗| = |2p − 1| < 1 Tr(ρ2) = 12(1 + |r⃗|2) < 1
  • Pure Superposition |+⟩ (p = 1, |r⃗| = 1): Density matrix ρ = [[0.5, 0.5], [0.5, 0.5]] has non-zero off-diagonal quantum coherences (0.5), enabling interference.
  • 50/50 Classical Mixture (p = 0.5, |r⃗| = 0): Density matrix ρ = I/2 = [[0.5, 0], [0, 0.5]] sits at the exact center origin of the Bloch ball. All off-diagonal coherences vanish (0.00), so no interference occurs.
